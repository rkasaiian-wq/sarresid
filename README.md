# سررسید

اپ سررسید شخصی برای گوشی (به‌صورت افقی) با پشتیبانی از S Pen.

## بخش‌ها
- **امروز**: کارهای روز (سمت راست) و صفحه‌ی دست‌نویس روز (سمت چپ). با کشیدن انگشت به چپ و راست، روز عوض می‌شود.
- **کارها**: همه‌ی کارها با فیلتر. برای تمام کردن کار، تیک بزنید یا با قلم رویش خط بکشید.
- **اشخاص**: افراد و شرکت‌ها، با تلفن، واتساپ، ایمیل، یادداشت دست‌نویس، و کارها و توافقات مرتبط.
- **توافقات**: طرف توافق، تاریخ، مبلغ، مهلت، یادآوری پیگیری، وضعیت، شرح دست‌نویس و عکس پیوست.
- **یادداشت‌ها**: صفحه‌ی بی‌انتها با قلم، متن تایپی، جدول، و نمودار (میله‌ای، خطی، دایره‌ای) از روی جدول.

## قلم
- فقط S Pen می‌نویسد و انگشت صفحه را جابه‌جا می‌کند (در تنظیمات قابل تغییر است).
- دکمه‌ی کنار قلم را نگه دارید تا پاک‌کن شود.
- بعد از کشیدن شکل، قلم را لحظه‌ای نگه دارید تا شکل صاف شود.
- ابزار کمند برای انتخاب، جابه‌جا کردن، تکثیر، تغییر رنگ و حذف.

## اجرا
این یک وب‌اپ نصب‌شدنی (PWA) بدون نیاز به سرور است. کافی است این پوشه روی یک آدرس https
(مثلاً GitHub Pages) قرار بگیرد، با Chrome در گوشی باز شود و از منو گزینه‌ی «نصب برنامه» زده شود.

برای اجرای محلی:

    python3 -m http.server 8000

## ساختار
- `js/ink.js` موتور نوشتن (قلم، پاک‌کن، کمند، تشخیص شکل، خط‌زدن کارها)
- `js/db.js` ذخیره‌سازی محلی (IndexedDB) و پشتیبان‌گیری
- `js/jalali.js` تقویم شمسی
- `js/views/*` بخش‌های اپ
